A.2Recover Homographies

I denote a point in the original image by $(x,y)$ and its corresponding point in the reference image by $(x',y')$. A homography $H$ is defined up to an overall scale. Fixing its bottom-right entry to one leaves eight unknown coefficients, $h_1,\ldots,h_8$.

Each matched point pair supplies two equations: one for $x'$ and one for $y'$. Therefore, four point correspondences provide eight equations, enough to solve for the eight unknowns when the system has full rank. The points must form a nondegenerate configuration; for example, four points with three on the same line do not provide a reliable projective frame.

1. Write the homogeneous point mapping and the eight unknowns.

\[ \lambda_i \begin{bmatrix}x_i'\\y_i'\\1\end{bmatrix} = \underbrace{\begin{bmatrix} h_1&h_2&h_3\\ h_4&h_5&h_6\\ h_7&h_8&1 \end{bmatrix}}_{H} \begin{bmatrix}x_i\\y_i\\1\end{bmatrix}, \qquad \mathbf h= \begin{bmatrix}h_1&h_2&h_3&h_4&h_5&h_6&h_7&h_8\end{bmatrix}^{T}. \]

2. Expand the matrix product into three scalar equations.

\[ \begin{aligned} \lambda_i x_i'&=h_1x_i+h_2y_i+h_3,\\ \lambda_i y_i'&=h_4x_i+h_5y_i+h_6,\\ \lambda_i&=h_7x_i+h_8y_i+1. \end{aligned} \]

3. Divide by the third coordinate to eliminate the homogeneous scale.

\[ x_i'=\frac{h_1x_i+h_2y_i+h_3}{h_7x_i+h_8y_i+1}, \qquad y_i'=\frac{h_4x_i+h_5y_i+h_6}{h_7x_i+h_8y_i+1}. \]

4. Multiply by the common denominator, then collect the unknown coefficients.

\[ \begin{aligned} x_i'(h_7x_i+h_8y_i+1)&=h_1x_i+h_2y_i+h_3,\\ y_i'(h_7x_i+h_8y_i+1)&=h_4x_i+h_5y_i+h_6. \end{aligned} \] \[ \begin{aligned} x_i h_1+y_i h_2+h_3-x_i x_i' h_7-y_i x_i' h_8&=x_i',\\ x_i h_4+y_i h_5+h_6-x_i y_i' h_7-y_i y_i' h_8&=y_i'. \end{aligned} \]

5. Read off the two coefficient rows contributed by point pair i.

\[ \underbrace{\begin{bmatrix} x_i&y_i&1&0&0&0&-x_i x_i'&-y_i x_i'\\ 0&0&0&x_i&y_i&1&-x_i y_i'&-y_i y_i' \end{bmatrix}}_{A_i} \mathbf h = \underbrace{\begin{bmatrix}x_i'\\y_i'\end{bmatrix}}_{\mathbf b_i}. \]

6. Stack all n point pairs and solve the least-squares problem.

\[ A=\begin{bmatrix}A_1\\A_2\\\vdots\\A_n\end{bmatrix} \in\mathbb R^{2n\times8}, \qquad \mathbf b=\begin{bmatrix}\mathbf b_1\\\mathbf b_2\\\vdots\\\mathbf b_n\end{bmatrix} \in\mathbb R^{2n}, \qquad \widehat{\mathbf h} =\underset{\mathbf h}{\arg\min}\,\|A\mathbf h-\mathbf b\|_2^2. \]

Homography implementation · computH.py

import numpy as np

def computH(im1_pts, im2_pts):
    n = len(im1_pts)
    A = []
    B = []
    for i in range(n):
        x1 = im1_pts[i][0]
        y1 = im1_pts[i][1]
        x2 = im2_pts[i][0]
        y2 = im2_pts[i][1]

        A.append([x1, y1, 1, 0, 0, 0, -x1*x2, -y1*x2])
        A.append([0, 0, 0, x1, y1, 1, -x1*y2, -y1*y2])
        B.append([x2])
        B.append([y2])

    A = np.array(A, dtype=float)
    B = np.array(B, dtype=float)

    print(A.shape)
    print(B.shape)

    return np.linalg.lstsq(A, B, rcond=None)[0]

A.3Warp the Images

I transform the four image corners to determine the output bounds. A translation then places negative coordinates on a valid canvas. To fill the destination without forward-mapping holes, each destination pixel is mapped back through $H^{-1}$ and sampled only when the source coordinate is inside the photograph.

\[\begin{bmatrix}\tilde x\\\tilde y\\\tilde w\end{bmatrix}=H^{-1}\begin{bmatrix}u\\v\\1\end{bmatrix},\qquad(x,y)=\left(\frac{\tilde x}{\tilde w},\frac{\tilde y}{\tilde w}\right).\]

Nearest neighbor rounds $(x,y)$ to one pixel:

\[(\hat{x},\hat{y})=\bigl(\operatorname{round}(x),\operatorname{round}(y)\bigr),\qquad I_{\mathrm{NN}}(x,y)=I(\hat{x},\hat{y}).\]

Bilinear sampling combines the four surrounding pixels with weights set by the fractional coordinates:

\[I(x,y)=(1-d_x)(1-d_y)I_{00}+d_x(1-d_y)I_{10}+(1-d_x)d_yI_{01}+d_xd_yI_{11}.\]

Interpolation implementation · inverse_sample.py

class inverse_sample():
    def nearest_sample(img, x, y):
        ix = int(round(x))
        iy = int(round(y))
        return img[iy, ix, :]
    def bilinear_sample(img, x, y):
        h, w = img.shape[:2]
        x0 = int(np.floor(x))
        y0 = int(np.floor(y))
        x1 = min(x0 + 1, w - 1)
        y1 = min(y0 + 1, h - 1)
        dx = x - x0
        dy = y - y0
        top = (1 - dx) * img[y0, x0, :] + dx * img[y0, x1, :]
        bottom = (1 - dx) * img[y1, x0, :] + dx * img[y1, x1, :]

        return (1 - dy) * top + dy * bottom

Each pair below shows the same 100 × 80 region from its rectified output, enlarged 6× with nearest-neighbor display scaling. The extra enlargement makes the original interpolation differences visible without adding another smoothing step.

Across all three examples, nearest-neighbor sampling preserves harder pixel boundaries, so text and barcode lines appear crisper, but diagonal and curved edges show more visible stair-stepping and blockiness. Bilinear sampling blends the four surrounding pixels, producing smoother transitions and less jagged geometry, while slightly softening fine text and other high-frequency detail.

A.4Blend the Images into a Mosaic

The blend splits each aligned image into a Gaussian low-frequency band and a residual high-frequency band, with $\sigma=6$. A distance transform assigns each pixel to the valid image farthest from its boundary. The high-frequency bands use that hard assignment, while normalized blurred masks mix the low-frequency colors.

\[L_i=G_6*I_i,\quad R_i=I_i-L_i,\quad M_i=\mathbf1\!\left[i=\operatorname*{arg\,max}_j d_j\right],\quad S_i=\frac{G_6*M_i}{\sum_j G_6*M_j},\qquad I=\sum_{i=1}^{3}(S_iL_i+M_iR_i).\]

Reflection

What I Learned

I learned how to use multiple pairs of corresponding points to project one image into another. By writing the point constraints as a linear system, I can solve for the homography that describes the projective transformation between the two views. Inverse warping then lets me map every output pixel back into a source image, while nearest-neighbor or bilinear interpolation determines how its color is sampled.

Accurate point selection is essential for alignment. Even a small error in a correspondence can become a visible displacement after the homography is applied, especially far from the selected points. These errors produce ghosting, doubled edges, and larger misalignments in the final mosaic. Using well-distributed points on the same scene plane gives a much more stable estimate, although parallax from objects at different depths cannot be removed by a single homography.

Blending is closely related to the multiresolution blending from Project 2: a Laplacian pyramid preserves details at different spatial frequencies while a smooth mask creates gradual transitions between images. Here, instead of drawing a simple mask by hand, I construct the selection mask from each warped image’s distance to its boundary. Pixels farther inside an image receive more confidence, so seams naturally avoid fragile edges and the method works better with the irregular footprints produced by projective warping. I also learned that blending can hide exposure and seam differences, but it cannot compensate for inaccurate geometry; good correspondence selection and a suitable projection must come first.
